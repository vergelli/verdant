# Code of conduct

This is a small project around a game we like. Keep it that way.

- Be kind. Assume the other person wants the addon to work as much as you do.
- Bug reports are welcome, including blunt ones. Insults are not.
- Disagree about code, not about people.
- No harassment, no discrimination, no publishing of anyone's private information.

If someone crosses a line, message @vergelli in game or open an issue. Comments or contributors that ignore this will be removed.

Adapted in spirit from the Contributor Covenant, version 2.1.
